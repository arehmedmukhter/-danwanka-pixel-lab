DANWANKA PIXEL LAB — iPhone-friendly browser editor

Included:
- Text layers: font family, size, bold/italic, alignment, fill, outline, shadow, gradient fill, letter spacing.
- Shapes: rectangle, ellipse, line, fill and outline.
- Image layers: import images, resize, rotate, opacity, brightness, contrast, saturation, grayscale, horizontal/vertical flip.
- Layer selection, ordering, duplicate, delete, object positioning and dimensions.
- Canvas size, solid/transparent background, PNG export, editable JSON project save/open, undo/redo.
- Responsive layout for iPhone Safari and desktop browsers.

How to use on iPhone:
1. Download and extract the ZIP in Files.
2. For reliable everyday use, upload the extracted index.html to a static web host.
3. Open its HTTPS URL in Safari.
4. Tap Share > Add to Home Screen.

Important:
This is an original browser editor inspired by common graphic design workflows, not an exact copy of PixelLab YD. It does not include proprietary PixelLab assets, every effect, automatic background removal, or a full font library. For background removal, use a dedicated remover and import the transparent PNG.
